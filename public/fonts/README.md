# Bundled fonts

Downloaded 7 November 2026 from Google Fonts. Both fonts use the SIL Open Font License; their license files are included here.

- DM Sans variable Latin subset, weights 400–700: https://fonts.gstatic.com/s/dmsans/v17/rP2Yp2ywxg089UriI5-g4vlH9VoD8Cmcqbu0-K4.woff2
- Noto Sans Sinhala variable Sinhala subset, weights 400–700: https://fonts.gstatic.com/s/notosanssinhala/v36/yMJ7MJBya43H0SUF_WmcBEEf4rQVO2P524V5N_MxQzQtb-t19Pqq4-E.woff2
- License sources: https://github.com/google/fonts/tree/main/ofl/dmsans and https://github.com/google/fonts/tree/main/ofl/notosanssinhala

Served locally with font-display: swap. Japanese uses installed system fonts (Yu Gothic, Hiragino Sans, Meiryo, then system fallback). There are no remote font requests at runtime. Check Japanese font rendering on actual target devices before launch.
