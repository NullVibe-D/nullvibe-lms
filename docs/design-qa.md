# Design QA

The current acceptance target is the user's selected white/light-blue lesson workspace plus their subsequent request for simpler, English-first discovery, clear language switching and smoother interaction. This revision deliberately changes the first landing screen to course discovery; it is not a pixel-match claim for the earlier generated lesson mock.

The lesson workspace preserves the principal anatomy: course sidebar on desktop, lesson heading, teacher illustration, learning note and actions, with examples and a reading guide alongside. Mobile replaces the sidebar with a selector. The new course page uses the same color, border and spacing system, clear beginner progression, and a lightweight type-based illustration.

Current-run screenshots and step-by-step findings are in UIUX-AUDIT.md. QA.md records browser sizes, language coverage, keyboard checks, automated accessibility scans and the limits of the evidence. No fabricated students, reviews, pass rates, prices or live-service capabilities were added.
